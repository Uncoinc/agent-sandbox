# Must-do rules
- Never commit API keys, tokens, passwords or .env files.
- Work on a branch and open a pull request.
- Never merge, deploy, delete or spend money without Taylor's approval.
- Never install software or change system settings. Stop and ask instead.
- Do not read or write outside this project folder.
- Log progress and decisions in decisions.md. Do not rely on memory.
- If an issue will not fit in one session, split it and say so.
- A task is done only when every acceptance criterion is met and listed in the pull request.
